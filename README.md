# 🗺️ 中国 56 个民族创世神话地图（China 56 Creation Myths Map）

一个纯前端、零构建、单文件可离线运行的交互式中国五十六个民族创世与族源神话数字图鉴。以标准 Albers 等积圆锥投影中国版图为基座，融合青绿金碧神话山河画卷、56 族手绘圆形贴纸、四大探索视图与双轨国风音频引擎，直观呈现中华各民族“多元一体”的创世想象与共同母题。

> **在线体验**：`https://<yeyan0254>.github.io/china-56-creation-myths-map/`  
> **当前版本**：`v3.8`

---

## ✨ 核心特性

- **标准合规中国版图 + 双底图一键切换**：采用标准 Albers 等积圆锥投影，完整呈现陆地国界（含藏南、阿克赛钦）、台湾岛、海南岛、钓鱼岛、赤尾屿及南海诸岛九段线框；全部 56 个民族严格归省定位。支持顶部一键切换 **「🎨 青绿画卷」**（20 地标 TPS 配准青绿金碧山河地形）与 **「🖤 暗墨青金」** 经典矢量风格。
- **四大交互探索视图**：
  1. **🗺️ 2D 国风地图**：高密度聚簇（云南/新疆/贵州/广西）智能聚合与放大展开、省级独占聚焦、分级 LOD 标签防重叠、Canvas 粒子氛围特效。
  2. **📜 创世时间轴**：按“混沌开辟 → 神体化生 → 造人繁衍 → 洪水再造 → 射日治水 → 族源迁徙”六大演进阶段纵向对比，支持筛选高亮与“仅看命中”切换。
  3. **✨ 母题图谱**：原生 HiDPI Canvas 星轨关系网络，内环 8 大创世母题星核与外环 56 民族星点实时联动。
  4. **🏔️ 2.5D 立体浮雕**：支持实时调节俯仰角（20°–55°）与旋转偏航角（-30°–+30°），1:1 屏幕空间贴纸与地面投影精准同步。
- **双轨零延迟声景与自由调音**：
  - 内置 **「十大民族器乐原型 × 56 族一族一韵」** Web Audio 合成引擎，并支持外置 `.wav` 高保真器乐包与 `.mp3` 真人原声共存。
  - 故事卡底部集成 **朗读 / 伴奏双轨独立音量滑块、快速静音、三档语速（0.85× / 1.0× / 1.15×）** 与普通话“配乐伴读”热开关（450ms 意境淡出尾音）。
  - 素材工坊内置自绘暗墨鎏金音色选择器，支持本地极速离线与 Microsoft Edge 免费云端神经语音切换、三档声线基调（沉稳说书 / 自然原声 / 清亮柔和）及独立试听。
- **内置素材工坊（零代码定制与固化）**：支持拖入本地图片自动裁圆压缩为 `256×256 WebP` 替换贴纸、拖入音频即时试装、一键导出固化单文件 HTML，以及导出 AI 贴纸提示词、配音脚本、批量配音 `.py` 与 Windows 双击 `.bat` 启动器。

## 📖 使用说明

### 1. 快速打开
- **在线访问**：直接打开上方 GitHub Pages 链接即可体验（推荐使用桌面端 **Microsoft Edge** 或 Chrome 浏览器）。
- **离线运行**：下载仓库中的 `index.html`，无需联网、无需搭建服务器，直接双击即可在浏览器流畅运行；若同时解压了高保真器乐包，只需把 `assets/` 文件夹放到与 `index.html` 同目录下，打开后会自动启用 56 族高保真 `.wav` 民族器乐声景。

### 2. 基础交互指南
| 操作 | 交互方式 |
| :--- | :--- |
| **缩放与平移地图** | 鼠标滚轮缩放、左键按住拖拽；也可使用右上角 `＋` / `－` / `⌖` 复位按钮 |
| **查看民族神话详情** | 点击地图上任意民族贴纸，或在左侧 `☰ 56 民族索引` 抽屉搜索民族、拼音、省份或关键词直达 |
| **探索高密度多族区** | 点击云南/新疆/贵州/广西聚簇玉佩，或单击对应省份自动聚焦展开省内全部民族 |
| **跨民族母题筛选** | 点击底部筛选栏的「相似母题 ⇄ 创世类型」按钮切换模式，点击任意胶囊（如“洪水再造”“射日降阳”）即可在全国地图、时间轴与图谱同步高亮并统计 |
| **切换四大视图与底图** | 顶部居中切换 `2D 国风地图 / 创世时间轴 / 母题图谱 / 2.5D 浮雕`；左上角点击 `🎨 青绿画卷` 切换经典 `🖤 暗墨青金` 底图 |
| **打开文献说明与素材工坊** | 点击右上角竖排题匾「中国五十六族创世图」 |

### 3. 朗读、调音与真人感配音指南
- **普通话配乐伴读**：点击故事卡底部的 **「🔊 普通话朗读」** 即可叠加该民族器乐伴读；点击 **「🎵 民族韵律」** 单独聆听该民族专属器乐；点击 **「🎶 伴读：开/关」** 可在朗读途中随时无缝开关背景器乐。
- **双轨独立调音**：拖动底部调音条分别调节 **朗读音量** 与 **伴奏音量**，点击图标快速静音/恢复，点击 **「语速 1.0×」** 循环切换三档语速（自动记忆保存）。
- **免安装听真人说书人级配音（无需 Python）**：
  1. 使用 Windows 系统自带的 **Microsoft Edge** 浏览器（联网）打开本页面（本地双击或在线 GitHub Pages 均可）。
  2. 点击右上角竖排题匾 → 切到 **「🎨 素材工坊」** → 普通话内置朗读选择 **「云端自然（Edge 免费神经语音）」**。
  3. 在暗墨鎏金音色下拉框中任选 **`★ 云健 · 说书男声`**、**`★ 晓晓 · 温婉女声`** 或 **`★ 云希 · 清朗男声`**，点击 **「🎧 试听」** 确认即可。
- **可选：挂载 56 族高保真 `.wav` 器乐包**：将 `assets/` 文件夹放到与 `index.html` 同一目录（或一起上传到 GitHub 仓库根目录），即可零配置自动升级为高保真 `.wav` 民族器乐独奏与伴读。

## 🛠️ 技术架构

- **纯原生前端栈**：Single-file HTML5 + CSS3 + Vanilla JavaScript（零框架、零外部 CDN、零 `fetch` 跨域报错）。
- **渲染引擎**：原生 SVG `viewBox` 矢量投影 + 1:1 屏幕空间贴纸层 + HiDPI Canvas 2D（粒子特效与星轨图谱）+ 零 SVG 高斯模糊滤镜高性能方案。
- **地理配准与视觉压缩**：内置 56 枚 `256×256 WebP` 国风圆形贴纸与 20 控制点薄板样条（TPS）配准双层 WebP 青绿山河画卷。
- **音频引擎**：Web Audio API 实时国风器乐合成 + HTML5 Audio 双轨混音 + Web Speech API 鲜活 `voiceURI` 音色调度。
